# Small introduction by Florian how to use DSP scripts

The DSP scripts are in the folder `dsp\` which contains at the moment three files:
- `dsp.jl` which contains the main functions for the DSP analysis
- `parallel.jl` which contains functions to call the DSP analysis and run in parallel
- `dsp_decayTime.jl` which can extract the decay time from the DSP analysis, but is not maintained at the moment
