# SiPM Calibration Parameters (pars_sipmcal)

This document describes the parameter structure for SiPM (Silicon Photomultiplier) calibration results generated by `process_sipm_calibration_phy.jl`. These parameters establish the conversion from raw ADC counts to calibrated photo-electron units for the Liquid Scintillator Veto (LSV) system.

## SiPM Physical Context and Calibration Purpose

**SiPM Technology:**
Silicon Photomultipliers (SiPMs) are solid-state photodetectors used in LEGEND-200's Liquid Scintillator Veto system. They detect scintillation light produced when particles interact with the liquid scintillator surrounding the germanium detectors.

**Photo-Electron Detection:**
- **1 PE (Photo-Electron)**: Basic unit of light detection - single photon converting to avalanche signal
- **Multi-PE Spectrum**: Multiple photons create discrete peaks at 1 PE, 2 PE, 3 PE, etc.
- **Gain**: Conversion factor from photons to electrical charge (ADC counts per PE)
- **Resolution**: Width of PE peaks, determines energy resolution

**Calibration Process:**
1. **Simple Calibration**: Initial linear conversion ADC → approximate PE units
2. **Multi-PE Fitting**: Precise fitting of 1 PE, 2 PE, 3 PE peaks in spectrum
3. **Final Calibration**: Polynomial mapping from ADC to calibrated PE units
4. **Quality Assessment**: Goodness-of-fit metrics and uncertainty propagation

## Hierarchical Field Structure

### **Level 1: Detector Identification**
```yaml
<detector_id>:  # SiPM detector identifier (e.g., "S073", "S060")
```
Top-level organization by individual SiPM detector. Each SiPM has independent calibration parameters due to varying gain and noise characteristics.

### **Level 2: Energy Estimator Type**
```yaml
  <energy_estimator>:  # SiPM filter type (e.g., "trig_max", "sg", "cusp")
```
Different DSP filter outputs optimized for SiPM signals, typically including trigger maximum and various shaped filters.

### **Level 3: Calibration Components**
```yaml
    fit:              # Multi-photo-electron peak fitting results
    cal:              # Final calibration curve parameters  
    m_cal_simple:     # Simple calibration constant (initial gain estimate)
```

### **Level 4.1: Peak Fitting Results (fit)**
```yaml
    fit:
      positions:         # Peak positions in ADC units
      positions_cal:     # Peak positions in calibrated PE units
      resolutions:       # Peak widths in ADC units
      resolutions_cal:   # Peak widths in calibrated PE units
      peaks:             # Photo-electron numbers (1, 2, 3, ...)
      n_pos_mixtures:    # Number of mixture components per peak
      n_mixtures:        # Total number of mixture components
      w:                 # Mixture weights with uncertainties
      μ:                 # Mixture means with uncertainties
      σ:                 # Mixture standard deviations with uncertainties
      gof:               # Goodness-of-fit metrics
```

**Field Descriptions:**
- **`positions`**: Raw ADC positions of PE peaks with uncertainties
- **`positions_cal`**: Calibrated positions in PE units with uncertainties  
- **`resolutions`**: FWHM of peaks in ADC units (measure of detector noise)
- **`resolutions_cal`**: FWHM in calibrated units (PE resolution)
- **`peaks`**: Integer PE numbers corresponding to each fitted peak
- **`n_pos_mixtures`**: Complexity of mixture model per peak
- **`w`, `μ`, `σ`**: Gaussian mixture parameters for detailed peak modeling

### **Level 4.2: Calibration Curve (cal)**
```yaml
    cal:
      func:           # Human-readable calibration expression
      func_err:       # Calibration expression with uncertainties
      μ:              # Peak means used for calibration fit
      par:            # Polynomial coefficients with uncertainties
      gof:            # Calibration curve goodness-of-fit
```

**Field Descriptions:**
- **`func`**: Mathematical expression for ADC → PE conversion
- **`func_err`**: Same expression showing parameter uncertainties
- **`μ`**: Peak positions used as calibration reference points
- **`par`**: Polynomial coefficients (typically linear: [offset, slope])
- **`gof`**: Quality metrics for calibration curve fitting

### **Level 5: Goodness-of-Fit Metrics**
```yaml
      gof:
        median_residuals:    # Median fitting residuals
        covmat:             # Covariance matrix of fit parameters
        pvalue:             # Statistical p-value of fit quality
        dof:                # Degrees of freedom in fit
        chi2:               # Chi-squared statistic
        residuals:          # Individual residuals array
```

**Interpretation:**
- **`pvalue > 0.05`**: Good fit quality (fail to reject null hypothesis)
- **`chi2/dof ≈ 1`**: Reasonable fit with appropriate model complexity
- **`median_residuals`**: Central tendency of fit deviations
- **`covmat`**: Parameter correlation and uncertainty information

## Example Structure

```yaml
# SiPM Calibration Parameters Example
S073:  # SiPM detector S073
  trig_max:  # Trigger maximum energy estimator
    fit:  # Multi-PE peak fitting results
      positions:  # Peak positions in ADC counts
        - val: 1.685  # 1 PE peak position
          err: 0.044  # Uncertainty in ADC counts
        - val: 2.503  # 2 PE peak position  
          err: 0.064
        - val: 3.354  # 3 PE peak position
          err: 0.151
      positions_cal:  # Same peaks in calibrated PE units
        - val: 0.953  # 1 PE calibrated position
          err: 0.052
        - val: 1.923  # 2 PE calibrated position
          err: 0.075
        - val: 2.931  # 3 PE calibrated position
          err: 0.180
      resolutions: [0.454, 0.175, 0.690]  # Peak widths in ADC
      resolutions_cal: [0.538, 0.208, 0.819]  # Peak widths in PE
      peaks: [1, 2, 3]  # Photo-electron numbers
      n_pos_mixtures: [5, 3, 2]  # Mixture complexity per peak
      n_mixtures: 15  # Total mixture components
      w: [...]  # Mixture weights (15 components with uncertainties)
      μ: [...]  # Mixture means (15 components with uncertainties)  
      σ: [...]  # Mixture standard deviations (15 components)
      gof:  # Peak fitting quality
        median_residuals: 0.210
        covmat: [[...]]  # Full covariance matrix
        pvalue: 0.234  # Good fit (p > 0.05)
        dof: 156
        chi2: 142.3  # Reasonable chi2/dof ≈ 0.91
        residuals: [...]  # Individual fit residuals
    cal:  # Final calibration curve
      func: "-1.04e + 1.21e .* trig_max"  # Linear calibration
      func_err: "(-1.04 ± 0.13)e .* (trig_max).^0 .+ (1.21 ± 0.061)e .* (trig_max).^1"
      μ: [1.685, 2.503, 3.354]  # Reference peak positions
      par:  # Calibration polynomial coefficients
        - val: -1.04  # Offset term
          err: 0.13   # Uncertainty
        - val: 1.21   # Slope term (gain)
          err: 0.061  # Uncertainty  
      gof:  # Calibration curve quality
        median_residuals: 0.089
        covmat: [[...]]  # Parameter covariance
        pvalue: 0.652   # Excellent fit
        dof: 1
        chi2: 0.203    # Very good chi2/dof
        residuals: [...]
    m_cal_simple: 1.186  # Simple calibration constant (ADC/PE)

S060:  # Another SiPM detector with different characteristics
  trig_max:
    # Similar structure but different values due to detector variation
    # ...

# Empty entries for detectors without successful calibration
S055: {}  # No calibration data (detector issue or insufficient statistics)
S031: {}  # No calibration data
```

## Interpretation Guidelines

**Quality Assessment:**
- **Good Calibration**: p-value > 0.05, χ²/dof ≈ 1, small residuals
- **PE Resolution**: `resolutions_cal[0]` gives 1 PE resolution (lower is better)
- **Gain Stability**: Compare `par[1]` across runs for detector stability
- **Multi-PE Capability**: Number of fitted peaks indicates dynamic range

**Physical Validation:**
- **Linear Gain**: Calibration should be approximately linear (pol_order = 1)
- **PE Separation**: Clear separation between 1 PE, 2 PE, 3 PE peaks
- **Gain Reasonableness**: Typical gains ~1-10 ADC counts per PE
- **Resolution Scaling**: PE resolution should improve with √(PE number)

**Usage in Analysis:**
- **Veto Efficiency**: Convert SiPM signals to PE for physics cuts
- **Light Yield**: Relate PE detection to energy deposition in scintillator
- **Detector Monitoring**: Track gain changes over time for detector health
- **Coincidence Analysis**: Use calibrated PE for multi-detector coincidences
